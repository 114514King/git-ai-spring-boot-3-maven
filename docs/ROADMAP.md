# AI 智能求职招聘平台路线图

## 项目愿景

构建一个前后端分离的 AI 智能求职招聘平台，支持学生投递岗位、HR 管理招聘流程、管理员维护系统数据，并通过 AI 匹配能力提升简历与岗位的匹配效率。

## 角色范围

### 学生

- 注册和登录
- 维护个人简历
- 浏览岗位列表和岗位详情
- 投递岗位
- 查看投递状态
- 查看 AI 匹配结果

### HR

- 注册和登录
- 发布和管理岗位
- 查看岗位投递列表
- 修改投递状态
- 查看简历与岗位匹配结果

### 管理员

- 管理用户
- 查看平台数据统计
- 查看统计图表和运营看板

## 技术路线

### 后端路线

1. 建立 Spring Boot 3 + Maven 基础工程。
2. 接入 MyBatis-Plus，连接 MySQL 8。
3. 设计用户、角色、简历、岗位、投递等核心表。
4. 实现统一返回格式、异常处理和参数校验。
5. 实现注册、登录、JWT 签发与校验。
6. 实现基于角色的权限控制。
7. 实现岗位、简历、投递等业务接口。
8. 接入 AI 匹配服务模块。
9. 接入 Redis 缓存热门岗位和岗位详情。
10. 补充部署文档和运行说明。

### 前端路线

1. 建立 Vue 3 + Vite 基础工程。
2. 接入 Element Plus、Axios、Pinia、Vue Router。
3. 实现登录、注册和路由守卫。
4. 实现学生端岗位、简历、投递页面。
5. 实现 HR 端岗位发布、投递管理页面。
6. 实现管理员用户管理和统计看板。
7. 使用 ECharts 展示关键统计数据。
8. 与后端接口完成联调。

## 迭代原则

- 每天只完成 `DAILY_TASKS.md` 中当天任务。
- 不跨天提前实现功能。
- 每次提交都保持项目可运行、可测试、可回滚。
- 每次任务完成后更新 README 和 DAILY_TASKS。
- 每次任务完成后运行构建或测试。
- 每次任务完成后提交一个清晰的 Git commit。
- 如果当前仓库连接 GitHub，任务完成后创建 Pull Request。
