## 实现与接口约定

管理员接口仍为 `GET /api/admin/evaluations/day30-controlled-comparison`，使用固定合成场景，复用业务 `SkillCoverageService`。新字段均为增加字段：

| 位置 | 字段 | 含义 |
| --- | --- | --- |
| 报告 | `qualityReviewStatus` | 恒为 `PENDING_HUMAN_REVIEW`，尚无人工质量结论 |
| 报告 | `qualityReviewSummary` | 明确规则证据、生成状态和风险提示已提供，人工审查尚未完成 |
| 场景 | `manualReviewStatus` | 恒为 `PENDING_HUMAN_REVIEW`，模型不能宣称人工已通过 |
| 场景 | `manualReviewChecklist` | 按生成/降级和缺口有无返回人工核验事项 |

清单核对合成输入、规则分和技能证据，区分遗漏/误述缺口、无依据经历及相对基线的具体追问或核验动作。模型未生成时额外贡献不可评估；无缺口时检查熟练度、真实性和岗位语境。规则分和招聘状态不由生成文本修改。

`docs/EVALUATION_MANUAL_REVIEW.md` 提供执行来源、北京时间、commit、输出文件、场景及三种哈希、复核人与原文证据的空白模板，明确默认降级/模拟/真实调用分别记录。本模块没有人工复核写接口或持久化，填写独立记录不会改变 API 的待复核状态。没有填写虚构复核人、实验数据或协作经历。
