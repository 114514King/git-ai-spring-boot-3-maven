# Day 35：真实 DeepSeek 合成受控比较

执行日期：2026-10-12，北京时间。当天只补真实模型受控比较验收，未推进其他模块。

## 结论与范围

真实适配器向官方 HTTPS 接口发出两轮、共 6 次固定合成请求，均返回 HTTP 200 / `GENERATED`。第一轮默认 512 token 的 3 份回答均截断；第二轮仅在测试进程覆盖为 2048 token / 30 秒，3 份回答全部 `stop`、未截断。两轮及各自禁用基线的规则分、技能、输入/规则/提示词哈希保持一致。

这完成真实传输、固定输入比较和规则隔离的技术验收。输出增加了可供审查的追问和核验动作，但尚无实际人工质量评分或招聘效果实验；所有人工状态继续为 `PENDING_HUMAN_REVIEW`。不将模型自称有价值或关键词检查结果当作已测得的效果。

调用路径为 `ControlledComparisonLiveIT → ControlledComparisonService → SkillCoverageService + DeepSeekChatClient → 官方 HTTPS`。使用真实生产服务和适配器，未启动 Spring Boot HTTP、浏览器、MySQL 或 Redis。没有读取、发送真实个人简历，也没有业务写入。
