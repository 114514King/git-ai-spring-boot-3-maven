## 实现证据

评估接口仍为 `GET /api/admin/evaluations/day30-controlled-comparison`，仅 ADMIN 可访问。Day 32 不新增业务路径、不新增数据库表、不修改评分公式、不调用真实模型。

报告新增 `scenarioSetVersion` 和 `scenarioSetHash`。前者标记固定合成场景版本，后者由全部场景的 ID、角色、岗位要求和简历文本计算，用于核对输入集合是否变化。

每个场景新增 3 个 SHA-256 十六进制哈希：

| 字段 | 含义 |
| --- | --- |
| `inputHash` | 单个固定场景的 ID、角色、岗位要求和简历文本 |
| `ruleEvidenceHash` | 规则模型、词典版本、规则分、所需技能、已匹配技能和缺口 |
| `modelPromptHash` | 服务端系统提示和发给模型的用户提示 |

`reproducibilityNotes` 明确说明：这些哈希用于核对同一合成输入、规则证据和提示词；`latencyMs`、模型文本和 token 用量可能随运行变化，不适合作为复现主键。哈希不证明真实 DeepSeek 调用、真实模型增益或真实招聘效果。
