# Day 29 验证与交付记录

执行日期：2026-10-05，北京时间。模块：学生/HR 前端助手与招聘状态人工确认。

## 实现范围

- 学生 `/app` 的“求职助手”、HR `/hr` 的“招聘助手”复用 Day 28 角色接口；请求只包含消息、可选会话 ID 及选定业务对象 ID，不接受前端系统提示或客户端历史。
- 通用、岗位/本人简历与投递上下文；切换上下文或新建对话清空页面历史、草稿和旧会话 ID。最近 24 条页面消息仅放内存，刷新/退出后不恢复。
- 空白消息和超过 1000 个 UTF-16 字符单位的消息禁止发送。发送中锁定输入/上下文，90 秒客户端超时；失败保留草稿和已成功消息，会话 403/404 提示新建，不自动重试。
- 回复使用 Vue 纯文本插值，规则分与来源独立展示。生成建议、降级状态和风险提示分别呈现；不解析回复为动作，不调用评分写接口。
- HR“人工复核投递”只切换到投递管理。选择新状态后弹窗展示投递 ID、原状态和目标状态，只有明确确认才调用既有 PATCH 接口。等待确认/更新时禁用状态选择，取消/关闭保持原状态。
- 无新增依赖、数据库表或迁移；真实业务数据访问权限仍由 Day 28 服务端校验。
